Spice Route Kitchen - Online Food Ordering Website
HTML, CSS and JavaScript project.
Features
Dynamic food menu (image, name, description, category, price)
Category filter and search by name
Add/remove items, increase/decrease quantity
Item subtotal and order total calculated dynamically
Order summary and customer details validation
Cart saved in Local Storage and restored on reopen
Messages for empty cart and order submitted
Run
Open index.html in a browser.
Deploy
GitHub repo -> Settings -> Pages -> Deploy from branch main / root.
